## 2024-06-03 - Memoize Zustand Store Array Reductions in High-Level Components
**Learning:** In React applications using Zustand, components that subscribe to the store often receive large array states (like `items`). If these components perform heavy array transformations (e.g., `.filter()` and `.reduce()`) directly in the component body, those calculations run on *every* render. Unrelated state updates (like toggling a modal, which updates local `useState`) will trigger these expensive recalculations, causing a performance bottleneck, especially as the number of items grows.
**Action:** Always memoize expensive data transformations (like filtering and reducing the Zustand store's array data) with `useMemo` in high-level components to prevent performance bottlenecks during unrelated state updates. Ensure dependency arrays are accurate (e.g., `[items, activeFilter]`).
