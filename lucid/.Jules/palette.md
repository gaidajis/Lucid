## 2024-07-02 - DataCard Keyboard Accessibility
**Learning:** When making `div` elements function as buttons (like `motion.div` in DataCard.tsx), simply adding `onClick`, `role="button"`, and `tabIndex={0}` isn't enough. We must handle the `onKeyDown` event for 'Enter' and 'Space', and critically, call `e.preventDefault()` on the 'Space' key to prevent the browser's default behavior of scrolling down the page. Additionally, we must conditionally strip these accessibility attributes (role, tabIndex, onKeyDown) when the component is placed into a non-interactive state (e.g. `editMode`).
**Action:** Always add `onKeyDown` with `e.preventDefault()` for 'Space' when creating custom accessible elements with `role="button"`. Ensure all interactive elements have visible focus states using `focus-visible` utility classes, adhering to the monochrome design system.
