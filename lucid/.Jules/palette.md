## 2024-05-24 - DataCard Keyboard Accessibility
**Learning:** Full-card clickables (like `DataCard` responding to `onClick` for modals) often lack keyboard support and focus visibility. Additionally, if the card state changes (like entering an edit mode where inner buttons become primary), the main card wrapper must dynamically drop its `role` and `tabIndex` to avoid confusing focus traps and double-focusing.
**Action:** Always pair `onClick` on non-button elements (like `div` or `motion.div`) with `role="button"`, `tabIndex={0}`, an `onKeyDown` handler (for `Enter` and `Space`, calling `e.preventDefault()` on Space to prevent page scroll), and `focus-visible` utility classes. Conditionally apply these only when the main element is the primary interactive target (e.g., `!editMode`).
