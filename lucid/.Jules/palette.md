## 2024-08-09 - Missing Keyboard Focus Indicators on Icon-Only Buttons
**Learning:** Icon-only buttons (close modals, toggle menu, add item, etc.) in the `lucid/` app were completely missing visual focus indicators (`focus-visible`). This makes keyboard navigation impossible for screen reader users and those relying on keyboard accessibility since they can't see what is currently focused. Also, `DataCard` had a custom `onClick` handler on a `motion.div` which was lacking the proper semantic requirements like `role="button"`, `tabIndex={0}`, and `onKeyDown` which breaks keyboard interaction on the card.
**Action:** Applied `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-black dark:focus-visible:ring-white` to all icon buttons to ensure clear keyboard navigation visibility. Also added a robust `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler to the `DataCard` so users can trigger `onView` with 'Enter' or 'Space' for full keyboard support. Added standard `e.preventDefault()` on 'Space' to stop scrolling.
