## 2024-05-28 - Accessible Interactive Cards and Dynamic Hover States
**Learning:** `onClick` handlers on non-button elements (like `motion.div`) in React lack built-in accessibility. They require manual implementations of `role="button"`, `tabIndex`, and keyboard event handlers (`onKeyDown` for Enter and Space) to ensure screen reader and keyboard navigation usability. Furthermore, when elements dynamically become non-interactive (e.g., during an "edit mode"), continuing to show `cursor-pointer` and hover effects creates cognitive dissonance.
**Action:** Always pair `onClick` with `role`, `tabIndex`, `onKeyDown`, and `focus-visible` styles on non-button elements. Dynamically disable hover and cursor pointer styles when an element's interactive state is toggled off (e.g., when the card's main click action is disabled in edit mode).
