## 2024-03-21 - Keyboard Accessibility on Non-Standard Interactive Elements
**Learning:** When using components like `motion.div` from Framer Motion as interactive elements (e.g., clickable cards), keyboard accessibility is completely lost by default. Screen readers don't recognize them as interactive, and they can't be navigated to via the Tab key or activated with Enter/Space, alienating users relying on keyboard navigation.
**Action:** Always ensure any `onClick` handler on a non-button element is accompanied by `role="button"`, `tabIndex={0}`, an `onKeyDown` handler to simulate click via 'Enter' or ' ', and robust `focus-visible` styles (`focus-visible:ring-2 focus-visible:ring-black dark:focus-visible:ring-white focus-visible:outline-none`) to provide clear visual feedback.
