## 2024-06-16 - Dynamic Keyboard Accessibility in React Cards
**Learning:** When turning generic `div` or `motion.div` elements into interactive cards that conditionally toggle interactability (like switching to `editMode`), it is crucial to fully sync keyboard accessibility semantics alongside mouse interactions. Leaving `tabIndex` or keyboard event listeners active when `onClick` is effectively disabled creates confusing and unreachable tab stops for screen reader and keyboard users. Additionally, when using `Space` to trigger card clicks, the default browser scroll behavior must be explicitly prevented via `e.preventDefault()`.
**Action:** Always conditionally apply `role="button"`, `tabIndex={0}`, `onKeyDown` handlers, and `focus-visible` utility classes together, ensuring they are only active when the element is truly interactive. Always call `e.preventDefault()` on `Space` keydowns for custom button roles to prevent jarring page scrolls.
