## 2026-06-13 - Keyboard Accessibility for Clickable Cards
**Learning:** In the Lucid app, the `DataCard` component is highly interactive (clicking it opens a modal), but it lacked keyboard support and focus indicators for non-mouse users, despite being a primary point of interaction.
**Action:** When a non-interactive element like `div` or `motion.div` is made interactive with an `onClick` handler, always provide `role="button"`, `tabIndex={0}`, an `onKeyDown` handler (for 'Enter' and 'Space'), and `focus-visible` utility classes (e.g., `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-black dark:focus-visible:ring-white`) to ensure it is accessible to keyboard users, being mindful to only apply these when the element is actually interactive (e.g., not disabled or in edit mode).
