## 2024-03-21 - Memoizing Zustand Derived State in Top-Level Components
**Learning:** In the `lucid/` architecture, the top-level `App` component extracts the full `items` array from the Zustand store and performs expensive array manipulations (filtering and mapping to `itemsByTier`) directly in the render function. Because `App` also handles UI state like modals (`addModalOpen`, `viewingItem`, etc.), these expensive calculations are re-run entirely unnecessarily whenever UI state changes. This is a critical pattern to watch out for when top-level components mix global state ingestion and local UI state.
**Action:** Always memoize derived arrays (like filters and grouping logic) using `useMemo` when components process Zustand arrays alongside local state that triggers frequent re-renders.
