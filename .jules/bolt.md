## 2024-06-15 - Memoizing expensive data transformations in React components
**Learning:** In applications using a global store like Zustand that holds an array of items, computing derived data (like filtering or grouping items into categories/tiers) in the main render body can become a severe performance bottleneck. Specifically, grouping using `filteredItems.filter` for every tier results in O(N * Tiers) complexity, and this calculation runs on *every* re-render triggered by unrelated state updates (like toggling an edit mode, or opening a modal).
**Action:** Always wrap expensive derived calculations (filtering and mapping/reducing) in high-level components with `useMemo`, ensuring dependencies are correctly listed (e.g. `[items, activeFilter]`). Furthermore, optimize grouping logic to construct an initial map and use a single O(N) `reduce` pass to bin items, rather than O(N*Tiers) nested iterations.
